# Phase 3C contextual reranking implementation and measurement

Nemotron contextual reranking receives only whitelisted candidate IDs, source metadata, page/section as stored, the original question, and validated constraints. The compact final prompt examines at most five passages of at most 700 characters each, uses a 900-token output cap, and requests a one-span JSON judgment. HIGH/MEDIUM judgments without an exact supporting span are rejected. A span must be present verbatim in the candidate passage. Unknown IDs, invalid labels, invalid spans, and invalid structured results are discarded. The accepted object is explicitly `UNVERIFIED_MODEL_PROPOSAL` with `classification_effect=NONE`.

The first 20-case pass used a much larger request and had 15 timeouts and one validation failure; only two rerank calls returned usable output. That pass is retained in `artifacts/phase3c_controlled_e2e_ablation_cases_v1.jsonl`. The compact v4 pass reused the same frozen candidate/gold set and expansion/Jev receipts. It issued 18 rerank requests: 14 returned usage and judgments, with one timeout, two invalid-JSON (`ValueError`) outcomes and one schema-validation outcome. Two cases had no candidate request. The pass contained 61 accepted candidate judgments: 19 HIGH, 5 MEDIUM, 33 LOW and 4 UNCERTAIN. All 24 positive HIGH/MEDIUM judgments carried verified spans. Eight proposed outputs were rejected for seven fabricated/non-verbatim spans and one missing positive span.

Across the eight objective expected-ID cases, C did not improve identity recall over deterministic A or the budget-matched A control: **7/8** at each measured cutoff. Reranking did change some order in review-required cases; for qi24, the PMMA suppression evidence ID moved from rank 1 to rank 3, which cannot be called helpful or harmful without independent relevance labels. No model result can promote DIRECT or RELATED. The code path keeps those fields and the scientific passage whitelist native-only.

**Decision:** `NEMOTRON_CONTEXTUAL_RERANKING_DECISION = KEEP_EXPERIMENTAL`. The compact prompt is operationally better than the initial one, but material relevance benefit is unproven, API output errors remain, and relevance gold is incomplete.
