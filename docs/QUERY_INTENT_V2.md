# QueryIntent V2

V2 replaces property-specific query fields with `EntityConstraintV2` and `PropertyConstraintV2`. A value retains reported unit/value and supports bounds or approximation. Examples: `hasMaterial=PMMA`; `AirflowVelocity LTE 0.1 m/s`; `OxygenConcentration BETWEEN 21.5–21.7%`. It is not yet the default retrieval contract.
