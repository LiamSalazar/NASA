# Extraction error analysis

The Phase-1 audited errors remain the governing sample: METHOD_AS_OBSERVATION (2), OBJECTIVE_AS_OPEN_QUESTION, TITLE_AS_CONCLUSION, IMPACT_AS_SAFETY_IMPLICATION, and DUPLICATE_CLAIM. The revised policy routes high-risk classes to review and accepts NONE. No bulk Phase-1.5 LLM extraction was run; scaling candidate volume before additional reviewed gold would produce misleading quality metrics.
