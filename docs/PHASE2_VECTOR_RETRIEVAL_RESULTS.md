# Phase 2 vector retrieval results

Executed with 6,054 provenance-resolvable passages: vector Recall@1/3/5/10 = 0.4500/0.7000/0.7250/0.8000; MRR = 0.5832, on the same 40 source-backed questions used for BM25. The fixed BM25 benchmark remains 0.6250/0.8500/0.8500/0.9000 and MRR 0.7226. Pure vector retrieval is not adopted as default.
