## Runtime and archives

Normal application services are `CurationService.submit_ntrs/submit/save`, `prepare_scientific`, `validate`, original retrieval and `export_package`. The supported `scripts/curate_research.py` CLI and Streamlit incorporation view invoke them. No Codex runtime, developer JSON correction, source-specific scientific mapping, automatic approval or baseline publication is required. Reserved-evaluation scripts add prospective boundary enforcement; production ingestion needs no reference answers.

Large JSON receipts, RDF snapshots and original execution logs may be stored as `.json.gz`, `.ttl.gz` or `.txt.gz`. `archive_manifest.json` records SHA-256 of the exact decompressed bytes and the compressed copy. Restore a receipt with Python `gzip.decompress` or `gzip -dc`; never substitute it for immutable raw input. Uncompressed local copies, generated SQLite/workspaces, PDF copies, exports and implementation ZIPs are intentionally excluded from Git. They remain locally available; no scientific originals or failed evaluation records were deleted. Original source URLs and checksums, complete extracted source text and table locators are retained in acquisition/prepared receipts. Reacquire official PDFs only after verifying their recorded hashes.
